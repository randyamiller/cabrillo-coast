Applied by blog/index.html (layout: blog, search: true) and, through _layouts/post.html, by every article in _posts/. blog/search.json uses layout: null and never reaches it. The home page index.html has no front matter, so Jekyll copies it unchanged and never applies this. Contracts checked by the built-page tests: - The Content-Security-Policy meta tag directly follows the charset tag, with nothing in between, because a meta policy governs only the markup after it. GitHub Pages allows no custom response headers, so this tag is the blog's only content-security control, and its value is fixed character for character. - The only script elements are main.js on every page (mobile menu, header shadow, footer year) and search.js where the page sets search: true. No inline script, event handler attribute, style element or base element: the policy or the tests reject each of them. - Every front-matter or configuration value printed into the markup passes through escape. - Local URLs pass through relative_url, and canonical and og:url through absolute_url, so links resolve on the custom domain (empty base path) and under a project path alike.
